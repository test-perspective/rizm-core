# 0.13.0 Release Notes 2026-04-05

## New Features

- Added collapsible Wiki and rich text fields in view mode.
- Added Wiki page move actions across projects and folders.

## Improvements

- Improved board column dragging with better previews and reordering feedback.
- Improved table sorting for task keys with numeric ordering.

## Bug Fixes

- Fixed label suggestions for Japanese input.
- Fixed Jira import cases where Markdown remained unrendered.
- Reduced failures when saving card updates after creating branches or pull requests.
